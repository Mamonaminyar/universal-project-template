# Universal Project Profiles

Universal Project Template provides technology-neutral project profiles for common software categories.

## Available Profiles

| Profile | Purpose |
|---|---|
| web | Web applications |
| api | APIs and backend services |
| ai | AI, agents and RAG systems |
| data | Data engineering and analytics |
| mobile | Mobile applications |
| enterprise | Enterprise-scale platforms |

## Principles

Every profile is:

- Production-oriented
- Security-aware
- Modular
- Testable
- Observable
- Documentation-driven
- Cloud-ready

Profiles describe engineering expectations rather than forcing a specific programming language or framework.

## Selecting a Profile

Choose the closest profile during project initialization.

A project may combine multiple profiles.

Examples:

- Web + API
- AI + API
- AI + Data
- Enterprise + API
- Mobile + API
- Enterprise + AI + Data

The profile is guidance and configuration metadata. It does not replace project-specific architecture decisions.
